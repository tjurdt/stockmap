# 視覺與資訊設計準則

這頁是「畫面要長怎樣」的決策依據。新頁面 / 新圖表照這裡做，不要各自發明。
token 在 `web/src/styles/tokens.css`，圖表配色在 `web/src/lib/palette.ts`。

## 為什麼要有這份文件

改版前的問題（都是實際量到的，不是感覺）：

- 字級用了 12 種、間距 9 種、全站都是 1px 灰框直角 —— 沒有層級，所有東西一樣重要＝沒有東西重要。
- 圖表色碼寫死在 `.tsx` 裡（違反專案自己的慣例），而且**會循環**：鎖定第 6 組策略會跟第 1 組同色。
- `0050` 基準線的綠 `#5b8c5a` 和比較色第 3 格**完全相同** —— 兩個不同實體同一個顏色。
- 散佈圖 60 個點**每個都永久標名字** —— 保證重疊，重疊的標籤等於沒標。
- 60 列 × 10 欄的明細表不能排序，也看不出哪兩欄是圖上正在畫的。

## 四條原則

### 1. 顏色依「職務」分配，不可互相借用

| 職務 | token | 只能表達 |
| --- | --- | --- |
| 狀態 | `--up` / `--down` / `--flat` | 漲跌（台股慣例：漲=紅、跌=綠）。**永遠不可以拿來當第 4 個系列色。** |
| 品牌 | `--accent` | 介面元素：連結、選取態、focus 環。不當資料色。 |
| 類別 | `--series-1…5` | 圖表上不同**實體**的身分（回測策略）。 |
| 中性 | `--ref`、`--chart-grid`、`--chart-axis` | 基準線、格線、軸 —— 刻意退到背景。 |

類別色的三條硬規則（`lib/palette.ts` + 測試守著）：

- **顏色跟著實體走，不跟著名次走。** 鎖定第 3 組策略時，前兩組的顏色不可以改變。
- **固定順序、不循環。** 只有 5 個位子，第 6 個以後折成「其他」，不要生新色。
- **基準線不是類別色。** 全部同一個中性灰，身分靠虛線樣式（`REF_DASH`），圖例畫出**實際的線**
  而不是實心方塊 —— 這樣才看得出哪條是哪條，也不會跟策略撞色。

色票取自已驗證的調色盤，跑過 CVD 檢查（白底、相鄰配對：CVD ΔE 16.3、一般視覺 ΔE 19.6，全數通過）。
`--series-4` / `--series-5` 對白底對比 < 3:1 → **用到它們的圖一定要同時有可見標籤**
（圖例 + 比較表），不可以只靠顏色說話。換色票要重跑驗證，不要用眼睛判斷。

### 2. 用尺度表達層級，不要用「再加一條框線」

字級 `--fs-xs…--fs-2xl`、間距 `--sp-1…--sp-6`、圓角 `--r-sm/md/lg`、陰影 `--shadow-1/2`。

- 一個區塊**只有一個主角**：結論用 `--fs-2xl`、重點數字 `--fs-lg`、其餘退到 `--fs-sm` 的 `--muted`。
- 卡片＝`--surface` + `--hair` 細框 + `--r-md` + `--shadow-1`。層級靠「浮起來多少」表達，
  不要靠加粗邊框或加深底色。
- 數字一律 `tabular-nums`（已在 `global.css` 全域開啟）—— 表格才對得齊，跳動的報價才不會左右抖。

### 3. 圖表：主角是資料，其餘都要退後

- **格線、軸用 `--chart-grid` / `--chart-axis`**，不要用 `--ink` 畫軸線。
- **直接標籤要選擇性。** 散佈圖依圓圈大小由大到小嘗試放置，會撞到已放的就跳過，上限 10 個；
  其餘滑過去才顯示（`FactorScatter.pickLabels`，有測試）。**不要每個點都標。**
- **命中區要比圖形大。** 散佈圖每點另加一個透明的 `max(r+6, 13)` 命中圓。
- **hover 要有焦點。** 滑過時其他點淡出到 0.28，視線只會落在一個點上。
- **顏色不能是唯一的編碼。** 有顏色就要有圖例；折線圖圖例畫實際線樣並顯示游標處的數值。
- **一張圖一個 y 軸。** 兩個量級不同的量 → 兩張圖，或指數化到同一基準（回測頁的做法）。

### 4. 密集資訊要給工具，不是給更多字

- 長表格：欄位標題可排序（同欄再點換升降冪），**空值一律沉底**——「沒資料」不該被讀成「最小」。
- 表與圖要互相呼應：散佈圖正在畫的兩個因子，在明細表把那兩欄標起來。
- 列要有 hover 底色，長表格才掃得動。
- 說明文字收進 `components/InfoHint`（ⓘ 鈕），一個區塊只留一句白話結論。

## 無障礙的底線

- 焦點一律看得見（`:focus-visible` 全域 2px `--accent` 外框）。
- 可排序表頭是真的 `<button>`，並標 `aria-sort`。
- 收合說明用 `aria-expanded` + `aria-controls`；**`[hidden]` 若被自訂 `display` 蓋掉要自己補
  `[hidden] { display: none }`**（踩過一次，見 `InfoHint.module.css` 的註解）。
- 顏色之外一定有文字或形狀可辨識（圖例、虛線樣式、狀態文字）。

## 還沒做的

- 深色模式：目前刻意只做淺色一套。要做的話，深色步階要重新挑並重跑驗證，不是把顏色反轉。
- 散佈圖的鍵盤瀏覽：60 個點逐一 tab 體驗很差，目前以明細表作為等價的可存取路徑。
